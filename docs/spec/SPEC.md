# SnipWave 仕様書 (MVP v0.1)

## 1. 概要
**SnipWave** は、PC上で再生されているシステム音声（ループバック音声）を「遡りキャプチャ」または「リアルタイム録音」の2パターンで即座に取り込み、アプリ上で波形トリミング・WAV書き出しができるクロスプラットフォーム常駐型サンプリングアプリです。

## 2. ターゲット環境・技術スタック
- **対応OS**: Windows 10/11, macOS 14.2+, Linux (PipeWire / PulseAudio)
- **開発言語**: Rust (Edition 2021)
- **GUI**: `eframe` / `egui`（WebView不使用・Pure Rust）
- **音声取得API（OS別）**:
  - **Windows**: WASAPI Loopback
  - **macOS**: Core Audio Process Tap (14.2+) / ScreenCaptureKit (12.3+)
  - **Linux**: PipeWire / PulseAudio Monitor ソース

## 3. コア機能要件 (MVP)

### 3.1 2パターンの録音・キャプチャ機能
1. **パターンA：遡りキャプチャ（Retroactive Catch）**
   - バックグラウンドで常にシステム音声をリングバッファへ書き込み続ける。
   - 「⏪ Catch」ボタン（または専用ホットキー）を押した瞬間、直前 `buffer_seconds` 秒分（デフォルト **30秒**）をスナップショットとして編集画面へ取り込む。
   - バッファの最大容量は300秒（5分、約115MB）で固定確保し、設定変更時のメモリ再確保による音途切れを防止する。
2. **パターンB：ライブ録音（Live Rec）**
   - 「● Rec」ボタン（または専用ホットキー）を押した時点からリアルタイムで新規録音を開始する。
   - もう一度押して「■ Stop」した時点で、録音開始〜終了までの音声データを編集画面へ取り込む。

### 3.2 波形表示・トリミング機能
- 取り込んだ音声（パターンA/B共通）の波形を `egui::Painter` で描画する。
- マウスドラッグまたはスライダーで **Start / End** の範囲を指定し、選択範囲の試聴再生（ループ再生含む）ができる。

### 3.3 WAV書き出し機能
- 指定したStart〜End範囲を非圧縮WAV（48kHz / 2ch / 32-bit float または 24-bit int）で書き出す。
- ファイル名は `snip_YYYYMMDD_HHMMSS.wav` を自動生成し、指定の出力先フォルダへ保存する。

### 3.4 設定・永続化
- **遡り秒数**: 5秒〜300秒の範囲で変更可能（デフォルト: 30秒）。
- **出力先ディレクトリ**: 任意のフォルダを指定可能（デフォルト: OSのミュージック/オーディオフォルダ）。
- 設定値はOS標準の設定フォルダへ `config.toml` として自動保存する。

## 4. 非機能要件・免責事項
- **パフォーマンス目標**: 常駐・待機時のCPU使用率 1〜3%以下、メモリ消費量 150MB以下。
- **免責事項**: 本ツールは個人の音楽制作・学習・検証用途を想定しています。YouTube、Netflix等の外部サービスから取得した音声の利用については、各サービスの利用規約および著作権法を遵守してください。
